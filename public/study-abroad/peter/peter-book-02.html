英國大學只拿 65 分，是不是快被當了？先別急著看到數字就緊張。如果孩子在英國大學一門課拿到 65 分，這其實不是「低分」，反而已經屬於相當不錯的成績。因為英國大學的評分方式，和台灣完全不是同一套邏輯。英國大學本科常見的成績分級： 70–100 分｜First Class Honours 一等榮譽學位 已經是非常優秀的表現。60–69 分｜Upper Second Class（2:1） 二等一榮譽 是英國大學非常重要的一個成績區間。

50–59 分｜Lower Second Class（2:2） 二等二榮譽 40–49 分｜Third Class 三等榮譽，通常也是本科的及格區間。39 分以下｜Fail 也就是說： 40 分通常就及格 60 分以上已經算不錯 70 分以上就是 First Class 80 分以上非常優秀 90 分以上在許多科系甚至相當少見 所以，千萬不要用台灣常見的「90 分才叫優秀、60 多分很普通」去解讀英國大學成績。

尤其在商科、社會科學、人文、法律、藝術設計等需要大量 essay、report、critical analysis 的科目中，老師給分通常相當嚴格。一篇論文如果拿到： 55 分：普通 62 分：不錯 68 分：已經很好 72 分：進入 First Class 75–79 分：非常優秀 80+：通常已經是極高水準 當然，數學、工程、程式設計或有標準答案的考試，90 分以上會相對比較有可能。那英國碩士呢？

碩士的標準又不太一樣： 70 分以上｜Distinction 60–69 分｜Merit 50–59 分｜Pass 50 分以下通常為不及格 所以如果孩子從英國傳訊息回家： 「爸媽，我這次只有 65 分。」 先不要罵。因為這個 65 分放在英國大學體系裡，很可能其實是一個相當漂亮的成績。

更重要的是，很多英國研究所申請、Graduate Scheme，甚至部分企業招聘，都會特別看學生最後是否取得： 2:1（Upper Second Class Honours）以上 這也是為什麼理解英國教育制度，比單純看一個「幾分」更重要。不同國家的教育體系，本來就有不同的評量文化。
