遊戲設計科系怎麼選？先分清楚你想做遊戲裡的哪一件事

加拿大、英國、美國、澳洲官方課程例子｜最後查核：2026-09-04

「Game Design」不是一條單一路線。學生若先把目標拆成玩法與關卡、程式與技術、美術與動畫、敘事與UX、製作與專案管理，再去看大學課程，會比先追綜合排名更容易找到適合自己的學程。

一、先分成五種方向

方向大學課程常見內容適合的學生
Game Designgame mechanics、level design、prototyping、playtesting喜歡規則、系統、玩家體驗
Programming / Development程式設計、引擎、graphics、systems、technical development數學與程式能力較強
Games Art / Animation3D modelling、character、environment、texturing、animation視覺、美術與造型能力較強
Narrative / UXstory、interactive narrative、interface、user experience喜歡寫作、互動與使用者研究
Productionproject management、team production、pipeline、portfolio擅長協作、企劃與統整

二、四個國家的課程例子，重點其實不同

加拿大｜Sheridan：跨領域 Game Design＋Co-op

Sheridan 的 Honours Bachelor of Game Design 把設計、敘事、程式與藝術放在同一個四年制學位中。官方課程可看到 Foundations of Game Design、Narrative Skills、Programming for Game Designers 等科目，並包含業界 Co-op work term；高年級以團隊製作遊戲為核心。這類課程適合想成為設計師、但又希望理解完整製作流程的學生。

英國｜Staffordshire：Design 與 Games Art 可分得更細

Staffordshire 的 Computer Games Design BSc 強調遊戲製作的創意與技術面，也有產業連結與專門設施；另外獨立的 Games Art BA 則把 3D modelling、digital sculpting、texturing、character design 與職涯作品集放得更重。這個例子提醒學生：英國選課時不能只看「Games」兩個字，要看它究竟偏 design 還是 art。

美國｜RIT：Game Design and Development 偏技術整合

RIT 使用「Game Design and Development」作為 BS 名稱，課程定位與其 Computing 學院背景相連。對希望把遊戲開發與程式、互動技術結合的學生而言，這種學程與純藝術型 Games Art 的學習體驗會很不同。

澳洲｜RMIT：Design studio 與互動媒體取向

RMIT 的 Bachelor of Games 強調 game design practice、產業連結與設計訓練；同校 Digital Design 也涵蓋 3D assets、games engines、immersive / extended reality。若學生興趣跨到互動媒體、XR 或 digital environments，就不必把搜尋範圍限制在名字含「Game Design」的學位。

三、選校時不要只做「排名表」

更實用的比較表至少要放六欄：核心課程、程式比重、美術比重、團隊專案、實習／Co-op、畢業作品。若申請需要作品集，再加入 portfolio 格式與審查方式；若偏技術，再查看高中數學或其他 prerequisite。

四、給高中生的 DIY 查校方法

  1. 先寫下你想做的工作：designer、programmer、artist、animator、UX、narrative 或 producer。
  2. 到大學官方課程頁，至少讀一年級與高年級必修，不只看招生首頁。
  3. 搜尋「capstone / final project / student work」，確認學生畢業時實際做出什麼。
  4. 確認實習是必修、選修，還是只有 career service；三者意義不同。
  5. 最後才比較地點、費用、排名與申請條件。
