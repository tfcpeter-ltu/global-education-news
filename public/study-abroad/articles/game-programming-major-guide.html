科系指南 · Game Programming

遊戲程式 Game Programming：核心其實是 Computer Science＋即時互動系統

官方資料重新整理｜最後查核：2026-09-04

Game Programming 跟 Game Design 不一樣。它更重 programming、data structures、algorithms、game engines、graphics、physics、AI 與 real-time systems。RIT 的 Game Design and Development BS 就明確把 game programming 放在 computing 核心中。

一、主要會讀什麼

常見課程包括 C++／C#、data structures、computer graphics、game engine architecture、physics、AI、networking、software engineering 與 team-based game projects。

二、和 Game Design、Game Art 差在哪

  • Game Programming：寫 code、做系統、引擎與 technical implementation。
  • Game Design：規則、玩法、關卡、玩家體驗與系統設計。
  • Game Art：角色、環境、動畫、3D asset 與 visual pipeline。

三、適合什麼學生

喜歡數學、程式、解 bug、做系統，而且願意花時間處理 technical details 的學生。若你只喜歡玩遊戲、但不喜歡 programming，Game Programming 未必適合。

四、申請前怎麼準備

高中優先把 Mathematics、Precalculus／Calculus、Physics 和 Programming 打好。RIT 對相關申請明確要求四年數學，並偏好 Calculus 與 Computing electives。自己做一個小型 game prototype、GitHub project 或 game jam 作品也很有幫助。

五、常見職涯

Gameplay Programmer、Engine Programmer、Graphics Programmer、Tools Programmer、Technical Designer、Simulation Developer、AR/VR Developer。
