藝術設計科系怎麼選？先看你想做「平面、動畫、電影、時尚、空間，還是建築」

Peter 的國際教育講座 × LTU 國際學術中心｜最後更新：2026-09-07

藝術設計是台灣學生很常出國念、也最需要看作品集與產業資源的領域。Graphic Design、Animation、Film、Fashion、Architecture、Interior Design 的訓練模式差很多，不能全部只放在 Art & Design 一個名稱裡。

一、視覺品牌與平面：Graphic / Visual Communication

會碰 typography、branding、editorial、digital design、motion、information design。適合喜歡圖像、排版、品牌與視覺敘事的學生。

→ 看 Visual Communication 指南

二、角色、動態與數位影像：Animation 動畫

2D / 3D animation、character、storyboarding、VFX、motion graphics、visual storytelling。作品集比一般學科成績更能反映適配度。

→ 看 Animation 指南

三、導演、攝影與影像製作：Film Production 電影製作

會碰 directing、cinematography、editing、sound、screenwriting、production。若想進電影、影集、廣告、內容製作，應看 production resources、industry links 與學生作品。

→ 看 Film Production 指南

四、服裝、材料與創意產業：Fashion Design 時尚設計

通常包含 design development、garment construction、textiles、fashion illustration、digital fashion、portfolio。若比較喜歡品牌與商業，則應看 Fashion Marketing / Fashion Management，而不是 Fashion Design。

五、空間與專業資格：Architecture 建築

Architecture 結合 design studio、history、technology、structures、environmental design。若目標成為建築師，要特別看當地 professional accreditation 與後續註冊路徑。

→ 看 Architecture 指南

六、室內空間與體驗：Interior Design 室內設計

更集中在 interior space、materials、lighting、human experience、spatial design，和 Architecture 的建築尺度與專業註冊路線不同。

→ 看 Interior Design 指南

七、台灣學生怎麼選最快

  • 平面、品牌、排版 → Graphic / Visual Communication
  • 角色、3D、動態 → Animation
  • 影像、導演、攝影 → Film Production
  • 服裝與材料 → Fashion Design
  • 建築物與城市空間 → Architecture
  • 室內與商業空間 → Interior Design

八、藝術設計留學真正該比較什麼

  1. Portfolio requirement 與作品風格是否匹配。
  2. Studio、equipment、workshop、software 與 production facilities。
  3. 畢業展、industry project、placement、城市創意產業。
  4. 藝術設計領域不要只用綜合 QS 排名判斷。
