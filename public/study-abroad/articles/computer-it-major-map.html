電腦／IT 科系怎麼選？先看你想「寫系統、做 AI、分析資料、做資安，還是做遊戲」

Peter 的國際教育講座 × LTU 國際學術中心｜最後更新：2026-09-07

對台灣學生來說，Computer Science 是最常見的海外升學主幹之一，但 CS、Software Engineering、AI、Data Science、Cybersecurity、Game Programming 的課程與職涯方向其實差很多。選錯名稱不一定會選錯職涯，但會影響大學四年的課程比重。

一、想保留最多選擇：Computer Science 電腦科學

最廣的入口。通常包含 Programming、Algorithms、Data Structures、Computer Systems、Databases、Operating Systems、Networks、Theory，之後再往 AI、Software、Security、Data、Graphics 等方向選修。

適合：還沒有決定細分方向，但數學、邏輯與程式能力不錯的學生。

二、想成為軟體工程師：Software Engineering 軟體工程

和 CS 相比，更重 software lifecycle、requirements、testing、team development、architecture、project management。若目標很明確是 software developer / engineer，可以優先比較這類課程。

注意：不同國家的 Software Engineering 可能放在 Engineering Faculty，也可能在 Computing School，先修科目可能不同。

三、想做 AI / Machine Learning：Artificial Intelligence 人工智慧

核心會更集中在 Machine Learning、Deep Learning、Linear Algebra、Probability、Optimization、NLP、Computer Vision。数学通常比一般学生想像中更重要。

適合：數學底子強，願意同時寫程式與理解模型的學生。

→ 看完整 Artificial Intelligence 指南

四、喜歡資料與模型：Data Science 資料科學

Statistics、Probability、Programming、Databases、Data Wrangling、Machine Learning 是常見核心。它比 CS 更偏資料，也比純 Statistics 更偏 computing。

→ 看完整 Data Science 指南

五、喜歡攻防與系統安全：Cybersecurity 資安

常見 Network Security、System Security、Cryptography、Secure Coding、Digital Forensics、Risk Management。對 Operating Systems、Networks、Programming 的理解仍然很重要。

→ 看完整 Cybersecurity 指南

六、想進遊戲產業：Game Programming

如果喜歡遊戲，但真正想做的是 engine、graphics、physics、networking、gameplay systems，應看 Game Programming / Game Development；若偏玩法、關卡、敘事、玩家體驗，則更接近 Game Design。

→ 看完整 Game Programming 指南

七、台灣學生怎麼選最快

  • 還沒決定細分方向 → Computer Science
  • 想當軟體工程師 → CS / Software Engineering
  • 數學強、想做模型 → AI / Data Science
  • 喜歡網路、攻防、安全 → Cybersecurity
  • 想進遊戲產業且愛寫程式 → Game Programming

八、申請前最重要的三件事

  1. 先查 Mathematics / Calculus prerequisite。
  2. 不要只看科系名稱，要看一年級到三年級必修。
  3. 比較 Co-op、internship、industry project，尤其若目標是就業或移民。
