# 原創數學練習集

題庫整合於 `https://cap-ai.ossdtw.com/math` 數學學習網站內；共用原本的導覽、登入與學習頁面。目錄、題本與詳解在站內切換，先前 `/math-original/` 連結導回數學網站的對應畫面。

56套，1,578個題目與子題。題型與數量取自先前核對的56套結構資料；編排分為17套會考型綜合練習及39套分單元段考型練習。不是官方試卷，也未使用原卷的題幹、圖形、解答文字、學校名稱或官方配分。

`blueprints.json`只保留年級、概略領域、題型與題數。每個題位以獨立撰寫的81種題目結構生成新題，另有證明與作圖結構。這是參數化練習集，不宣稱1,578種互異的數學解法，也不宣稱與原題逐題等難。原卷大題／子題分組未重建；頁面清楚標示為題目／子題數。

題本與詳解分頁。數值題有列式與推導、易錯提醒；選擇題附四選項核對；非選擇題有本站評分規準。作圖為紙筆任務，證明與作圖須人工批改。自訂原始配分依各卷換算百分制，非官方評分標準。

本批不呼叫任何AI供應商API。產生及閱讀均不需要金鑰。未將本批靜態練習自動混入既有會員模考及弱點紀錄。

重建：`node scripts/build-original-math.mjs`

核驗：`node scripts/original-math.test.mjs`

核驗範圍：56套的題型與題數、1,578個不重複題幹、1,552題數值的獨立模型核算、11題證明與15題作圖的解答及配分完整性、選項唯一性、學生題本不含詳解、來源內容隔離。證明與作圖的論證由撰題時直接核對；自動檢查不等同形式化數學證明或難度實測。
