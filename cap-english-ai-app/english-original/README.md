# 56套原創英文練習

本題庫是英文學習網站內的功能模組，統一由 `https://cap-ai.ossdtw.com/` 進入。首頁與原創題庫共用主網站；以頁內路由切換目錄、學生題本與詳解，原有學習頁保留。先前的 `/english-original/` 及題本連結會導回主網站內的對應畫面。

每套閱讀43題、聽力21題，另附2題手寫延伸。共3,584題選擇題、112題手寫；448篇題組文章與1,176題聽力稿，均由新建主題與題型模板產生，不讀取原卷、出版題庫或舊版英文題庫內容。

56個主題涵蓋社區、校園、環境與生活。每套使用共同結構：19題字彙文法，兩篇各3題的克漏字，六篇各3題的閱讀；聽力為辨識句意3題、基本問答7題、言談理解11題。這是本站練習編排，非逐年原卷題型比例的重建，也不宣稱逐題等難。參考評量方向：https://cap-rcpet.rcpet.edu.tw/test5-3.html 。沒有重製官方例題。

題本與詳解分冊。逐題附證據、判讀步驟、語言規則與全部選項理由；克漏字附填回後完整文章。手寫附範文、字數要求與自訂10分規準，需人工批改，不計入64題，也不以範文作唯一正解。閱讀與聽力分開顯示題數，不換算官方等級。

聽力採裝置SpeechSynthesis朗讀，或由教師讀取詳解冊原創稿；沒有付費TTS API、真人錄音或專業錄音室製作。聲音與語速取決於裝置，部分裝置可能無可用英文聲音。學生頁的朗讀資料是公開練習素材，不是安全封存考卷。

本次不呼叫OpenAI或其他付費模型API，不使用金鑰。新靜態練習集不自動寫入既有會員模考成績、弱點與筆記。

重建：`node scripts/build-original-english.mjs`

檢查：`node scripts/original-english.test.mjs`

檢查包含每套題數與題型、唯一ID、448篇不重複文章、證據確實位於文章或聽力稿、選項唯一、正解索引、所有選項解說完整性、克漏字填回、範文字數、聽力數字與時間條件，以及學生題本與教師詳解分離。這些檢查不等同語言教學成效或難度的實測。
