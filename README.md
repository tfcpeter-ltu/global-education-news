# Global Education News

A Taiwan-based international education news and analysis publication focused on global higher education, admissions, policy, student mobility, international schools, and evidence-based commentary.

## Working title

**Global Education News｜國際教育新聞網**

This repository contains the publication website, editorial pages, SEO/news structured data, and article archive.

## Editorial principles

- Original reporting and analysis
- Clear attribution to primary sources
- Transparent corrections and updates
- Separation of editorial content from commercial/partner information
- Traditional Chinese (Taiwan) as the primary editorial language

## Technology

Built as a static-first Astro website for fast loading, strong crawlability, and easy deployment to GitHub Pages or a custom domain.
