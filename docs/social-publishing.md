# 新聞發布後社群宣傳流程

本文件是 Global Education News｜環球教育新聞的標準編輯工作流程，與根目錄 [AGENTS.md](../AGENTS.md) 一併遵循。中文一律使用繁體中文、台灣用字。

## 適用時機與完成條件

- 每當 src/pages/news/ 新增正式新聞文章，必須同步建立社群內容資料。
- src/pages/scholarships/ 新增重要獎學金內容時也必須建立；例如台灣學生可申請的新梯次、重要全額／高額補助、重大資格或截止日變化。以讀者實用性判斷，在資料中加上 selectionReason 說明選題理由。
- 單純版面調整、索引更新或大量種子資料產生，不代表每個產生檔都是新選題；以正式文章 canonical URL 去重。
- 文案可隨文章準備，但必須等正式文章部署成功、正式網址與圖片驗收、內容及來源複核後，才標為 ready。
- 使用者於 2026-09-09 已授權 Codex 自動接手網站及 FB／IG／X 宣傳；通過本流程查核後可向交接紀錄中的既有帳號發布，不需逐篇詢問。帳號與排程狀態見 [Codex 交接紀錄](codex-handover.md)。
- 現行發布平台是 Facebook、Instagram、X；保留 threadsCopy 供後續使用，不因保留欄位就同步發布 Threads。X 尚未連線時只準備文案，不阻擋其他可執行工作。

## 儲存方式

每篇一份 UTF-8 JSON，存於 docs/social-posts/YYYY-MM-DD/<type>--<slug>.json；日期採首次建檔的台灣日期，type 為 news 或 scholarship，slug 沿用文章路徑識別名稱。

建檔前搜尋既有 articleUrl：同篇修改原檔並更新 articleCommit／verifiedAt，不因重跑、改日期或換平台而另建重複資料。相同主題的實質政策更正，保留已發布紀錄並重新審核三平台文案。

資料檔放在 docs/，不放 public/ 或 src/pages/；尚未核准的文案與圖片需求不應自動成為正式網站頁面。

## 必備欄位

以下欄位每份都必須存在。ready 資料除另有說明外不得為空，不能留模板文字。

| 欄位 | 格式與用途 |
| --- | --- |
| articleTitle | 正式文章標題，維持已查核事實與政策狀態。 |
| articleUrl | https://globalednews.com/ 下的完整 canonical URL，以部署後頁面核對，不猜測 slug 或尾斜線。 |
| shortHook | Threads／IG 第一個吸引句，以已核對數字、截止日期、政策變化或具體問題開場。 |
| facebookCopy | 可直接閱讀的 3–5 段完整貼文，以空行分段，包含背景、影響及全文連結。 |
| instagramCopy | 比 FB 精簡，以圖片為核心；前兩行放亮點與必要限制，導流可用「完整內容見首頁連結／Global Education News」。 |
| threadsCopy | 短版文字，第一句具體，保留關鍵適用條件，附全文連結。 |
| xCopy | 獨立短版 X 文字，具體開場、必要條件與全文網址；送出前依當時平台介面核對限制。 |
| CTA | 僅取「閱讀全文」「收藏」「分享」「追蹤」「免費加入會員」其一，依下節輪替。 |
| socialImage | 可用圖片的完整 URL；優先該文章 OG 圖或新聞實景照片。缺圖時為 null，且必填 imageRequest。 |
| imageAlt | 對實際選用圖片的繁體中文描述；不堆關鍵字，不把資料照描述成事件現場。缺圖時可為 null，補圖後必填。 |
| category | 沿用正式文章分類。 |
| topic | 沿用正式文章主題；獎學金無此欄時依內容指定 scholarships，並保留 country／level 等補充分類。 |

另保留 sourcePath、articleCommit、sources（含已查核官方與獨立第二來源）、verifiedAt（含時區）、status、ctaDate、plannedPublishDate、imageSource、imageCredit、imageLicense 與 publishedPosts，以便回查。

status 使用 draft、needs-image、ready、published 或 needs-revision。publishedPosts 記錄實際成功的各平台 URL／時間；只完成部分平台時仍保留各平台明細，不把未送出平台寫成成功。

## 品牌定位與平台差異

每個平台版本都要保留以下兩個定位的意義，依內容輪換語句、位置及長短，不每篇逐字貼上同一段：

> 台灣第一個專注國際教育的新聞網站｜Global Education News 環球教育新聞

> 免費加入會員，每週接收最新國際教育政策、海外大學招生與國際獎學金消息。

可交替使用完整品牌句與較自然的表述，例如「從台灣出發，專注國際教育的 Global Education News 環球教育新聞」、「政策、海外大學招生與國際獎學金，每週透過免費會員週報掌握」。前者是定位的改寫，不宣稱已獨立查證市場排名；不得延伸成「唯一」「最大」或其他無依據的優越性宣稱。

- X：以已核對數字、期限、政策變化或問題開場，保留必要條件及全文連結。使用獨立文案；不得未經指示拆成串文，發布工具回報超限時依工具規則處理。
- Threads：第一句直接提出數字、期限、變化或具體問題。沒有數字就用來源支持的變化或問題，不能為吸引注意杜撰數字。篇幅短、語氣清楚；必要條件不能因縮短而省略。
- Facebook：3–5 段，依序安排亮點、背景／主要變化、對台灣學生與家長的影響、品牌與行動。全文 URL 必須可見且可用。
- Instagram：先決定圖片與重點，再寫 caption；前兩行不塞制式品牌介紹。精簡說明與圖片相符的事實，保留必要限制；若用「首頁連結」，實際發布前確認帳號首頁確有正確入口。
- 同一天可使用同一主題，但三份文案需調整開場、資訊密度、段落與導流方式，不可完整複製貼上。
- 免費會員／週報價值可作資訊性收尾；每篇主要行動仍以 CTA 欄位為準，避免所有貼文最後都變成相同的會員 CTA。
- 發送前以當時平台編輯器檢查文字與圖片預覽；不把本文件當成永遠有效的平台字數或尺寸上限。

## CTA 輪替與跨 session 紀錄

以台灣日期的「發布日批次」作為輪替單位，同日三平台及多篇內容可共享當日 CTA；下一個有發布安排的日期依序前進一格：

閱讀全文 → 收藏 → 分享 → 追蹤 → 免費加入會員 → 閱讀全文。

- 維護 docs/social-posts/cta-history.json。首次真正安排社群資料時建立；本次文件變更不虛構歷史發布紀錄。
- 每日紀錄包含 date、CTA、status（planned／published／cancelled）及 contentFiles。讀取已發布與已排定紀錄後，才能為新日期選 CTA。
- 無歷史資料時以「閱讀全文」開始；有既有外部發文紀錄時先查可取得的最近紀錄。無法取得時註明 historyIncomplete，不宣稱已驗證跨日去重。
- 空白日不消耗輪替；同日重跑沿用已分配 CTA。插入、取消或改期時，只重算尚未發布的安排，保持依序輪替且相鄰發布日不重複；已發布紀錄不可覆寫。
- 三平台可用不同措辭表達同一主要行動，例如收藏／先存下申請提醒，但 CTA 欄位保持固定值。
- 實際發布前再次核對日期、最新排程與上一發布日 CTA；只有成功送出才記為 published。
- 「閱讀全文」連到 articleUrl；「免費加入會員」導向當時正式站可操作的免費訂閱入口（目前為 /newsletter/，發布前再驗證），不得假造帳號、表單或會員權益。
- 併行任務在提交前重新讀取 main 的紀錄，避免重複分配；不要只依本次對話記憶決定 CTA。

## 事實、來源與時效

- 社群資料沿用文章已完成的雙重查核，至少一個第一手官方來源、一個彼此獨立的可信第二來源。來源及重要限制保留於資料中，不能只複製媒體標題。
- 重大政策核對官方原文、發布／生效日期、適用對象、例外與數字。社群不得新增文章未支持的推論，也不能把提案或待生效措施寫成已實施。
- 距離新聞發布已有時間時，發社群前重查是否有更正、延後、撤回或新進展；文案與正式文章不一致時先修正，不繼續導流舊資訊。
- 獎學金再確認台灣資格、是否仍開放、截止日期與時區、補助及條件，不把已截止或不適用台灣者寫成可申請機會。
- 不用無日期的「今天截止」「明天生效」製造過期文案；預設寫明絕對日期，確有需要用相對日期時依實際發布日重算。
- LTU／合作內容沿用文章必要利益揭露，不能包裝成獨立第三方評測。

## 圖片選擇與缺圖需求

1. 開啟正式文章，確認實際 og:image 與新聞主圖。
2. 優先選文章 OG 圖或相關新聞實景照片，但須確認授權涵蓋社群使用與必要裁切／署名；有 OG 圖不代表可任意再利用。
3. 共用預設 OG 圖、無關資料照、載入失敗或授權不明圖片，不算合適圖片。保留原始來源、署名與授權依據。
4. 預覽各平台裁切，避免重要文字、校名或人物被切掉；不得將資料照誤標為新聞現場。
5. 無合適圖片時仍建立內容資料：socialImage、imageAlt 設 null，status 設 needs-image，填入 imageRequest（缺圖原因、主題、必備已查核文字、用途、版型需求、授權要求與待辦狀態）。不得自行使用授權不明照片。
6. 補圖後確認可存取、清楚可讀、imageAlt 正確及與近期其他文章去重，再將狀態改為 ready。圖片需求不是已完成圖片，不可將 IG 標記可發布。
7. 同篇內容可跨三平台沿用同圖或製作合適裁切；不同文章仍遵守 AGENTS.md 的主圖去重規則。

## 每次發稿的交接檢查

- 同步交付正式文章與社群 JSON；重要獎學金另填選題理由。
- 核對所有必備欄位、JSON 語法、來源、日期、平台差異、FB 段落數及主要 CTA。
- 查看近期文案與 CTA 紀錄，避免連續使用同句品牌收尾、相同 hook 或跨日相同 CTA。
- 文章部署及正式站驗收通過，URL／OG 圖可用，圖片授權與裁切檢查完成，才改為 ready；缺圖則交付 needs-image 與需求。
- 文章更正或改期時同步更新社群資料；已發布者另記需要更正的平台，不默默刪掉舊發布紀錄。
- 回報資料檔位置、ready／needs-image 等狀態、CTA 日期與未解決事項；清楚區分「資料已備妥」及「平台已發布」。

## 實際發布與失敗處理

- 發布前確認正式文章、來源、圖片及授權，讀取平台近期貼文與已排程內容；以 articleUrl × 平台 × 版本去重。
- 每平台留存發布意圖、目的帳號、回傳 ID、狀態、貼文 URL 與時間。先記錄意圖再送出，回讀平台結果後才記為成功。
- 排定不等於已發布；部分成功時分平台記錄。逾時或結果不明時先查平台，不盲目重送。
- X 尚未連線或圖片不合格時標記該平台 blocked／needs-image，保留可用文案；不把其他已完成的平台回滾或重發。
