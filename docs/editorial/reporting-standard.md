# 國際教育新聞報導標準

2026-11-06 使用者要求修正新聞過短、缺乏前因後果的問題。本標準適用於往後每日維護及舊文實質重寫，不建立額外自動化。

完整報導須回答：發生什麼、為何現在重要、原有制度或問題、事件如何發展、不同當事方與獨立專家如何理解、證據能支持什麼結論、對台灣讀者的具體影響，以及下一個值得追蹤的節點。以連貫敘事連接事實，不以三段摘要、條列摘要或泛用申請提醒充當新聞全文。

一般完整報導目標為繁體中文正文1,200–2,000字；機械檢查底線900中文字與8個敘事段落，不計方法說明。長度僅能排除明顯短訊，不能證明深度。不得用套話、重複背景、無證據因果或虛構人物補足字數。資料不足以完成報導時換題研究；短訊不計每日三篇完整報導。

每篇至少實讀一個第一手來源及一個獨立可信來源，註記來源角色、日期、關鍵主張及獨立性。主辦公告與轉載同一公告不算兩個來源；同一專家文章的原刊與轉載不算兩份證據。區分官方目標、公布規則、已實施結果與編輯分析。來源列出機構與具體文件名稱，禁止 Source 1 之類無資訊標籤。

每篇應交代報導方法。未親自採訪，不使用「本報訪問」「現場直擊」或捏造引語；轉述其他媒體採訪時說明誰訪問、誰發言。不得為了形式上的平衡加入沒有來源的反方意見。未知因果應如實寫未知，並解釋需要哪些資料才能判斷。

完整中英文同時準備；英文保留背景、限制與分析，不能縮回短摘要。保留原發布日期，實質擴寫用 updated 與文末說明。發布前逐篇在 news-reviews.json 記錄六項內容判斷及來源獨立性，綁定正文雜湊；修改正文後必須重新審閱。建置與每日驗證都執行 check-news-depth.mjs。

舊文盤點見 2026-11-06-depth-audit-before.json。191篇中184篇少於900中文字；這是待審查訊號，不等於每篇均已判定為劣稿。修復順序為首頁及近期新聞、仍影響申請決策的政策、其餘歷史報導。每篇須重查來源與當時脈絡，不能把今日資訊悄悄倒填為舊聞。未重寫項目保留待辦，不宣稱全站已完成。
