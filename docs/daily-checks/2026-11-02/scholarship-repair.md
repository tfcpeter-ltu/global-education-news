## 找到並修正的原因

1. 舊「開放中」是靜態文字，時間經過不會失效。加入已知精確截止判斷、七日查核失效與期限當日待複查機制；沒有官方時間時，不捏造截止時刻。
2. 列表一律顯示「台灣資格已查核」，未區分種子資料及過期資料。改為逐筆日期、狀態與資格限制提示。
3. 頁首建置日期容易被理解成全庫當日完整查核。改為實際全庫盤點日期，明確區分時程盤點與完整資格查核。
4. 今日精選僅在建置時判斷日期。加入Asia/Taipei午夜失效與可見頁面更新，連帶更新精選數量。
5. 本機工作副本Vite套件檔案缺失，造成首次建置失敗。依既有鎖定版本重新安裝修復，套件留在OneDrive外，原始碼相依版本未變。
