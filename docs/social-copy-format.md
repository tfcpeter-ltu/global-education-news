# 社群宣傳固定格式：主題、入口、精選、會員

2026-09-16 使用者最新指示。適用新聞、獎學金、留學 DIY、國內大學資料庫及所有每日宣傳平台。若舊文件有「先寫 hook」「品牌後置」「輪替主要 CTA」等內容，以本文件為準。每日台灣時間 08:00 前完成的期限與十五則平台配置維持。

## 固定順序

1. 第一行為網站專區主題，不能先放單篇消息、問句、emoji 或 hashtag。
2. 第二行為正式專區連結。
3. 空行後寫「最新消息」，再寫已篩選、查核的內容；常青選校故事標「最新消息｜本日精選」，不得暗示歷史事實剛發生。
4. 精選內容應交代對讀者的用處、必要資格與期限。可附全文連結與圖片來源。
5. 結尾固定為會員邀請、實際好處及會員入口；收藏、分享只能是次要呼籲。

## 平台與驗收

- 2026-10-03 空白預覽修正：Facebook 貼文包含多個網址時可能選到文末電子報連結。發文必須另上傳至少一張已查核圖片，不得只靠連結卡片；選擇主要文章的卡片，確認會員連結沒有取代它。文案仍保留會員入口。
- 發布前執行 `node scripts/verify-social-preview.mjs <文章正式網址> https://globalednews.com/newsletter/`；未通過不得發布。本站所有可分享頁面在建置末段自動產生獨立、帶標題的本站 PNG 預覽圖，不再讓社群爬蟲直接依賴外站圖片轉址。
- 發布後回讀公開 Facebook 貼文，圖片實際可見才記錄 `mediaKind=uploaded-photo`、`mediaStatus=VERIFIED`、`mediaEvidence`、`mediaVerifiedAt`、`previewStatus=VERIFIED`、`previewVerifiedAt`。只有 imageCount 或連結卡片存在不算通過。
- 舊 Facebook 卡片可能保留平台快取；網站部署成功不代表舊貼文已修復。需另外回讀原貼文，能編輯時修復原貼文並記錄；不能編輯則記為待處理，禁止以重發冒充修復。

- Threads：控制在平台字數限制內，保留前兩行與會員入口；超過編輯期限的既有貼文記為不可編輯，不當作新版已發布，不為改格式重複發文。
- IG：前兩行同樣保留，不能聲稱 caption 網址一定可直接點擊。必要時提示複製網址至瀏覽器；只有驗證個人檔案入口正確才能寫「首頁連結」。
- LinkedIn／Facebook：前兩行保持相同結構，後文依學生、家長及教育工作者需求調整。平台可能自動縮短連結；核對提交目的地。
- 新製作的封面優先呈現網站主題與讀者價值，精選消息為次標。既有真實照片、截圖、署名與授權要求維持。
- 先核對完整編輯器內容，再儲存並回讀公開貼文。文案檔用 copyVersion、copyHistory、revisions 分別記錄新稿與已成功平台修改；不得以草稿更新冒充平台更新。
