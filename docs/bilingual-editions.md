# 中英文版

中文原網址保留，英文版使用 `/en/` 加原路徑。新聞、Peter、獎學金與本站 HTML 工具頁皆由同一份中文內容建立英文頁；讀者可在頁首切換同一篇內容，查詢參數與錨點會保留。語言偏好儲存在目前瀏覽器，儲存不可用時仍可用普通連結切換。

英文版清楚標示為機器翻譯，並提供中文原文及原有官方來源。英文版不是獨立的官方招生或政策文件。第三方嵌入服務與圖片中既有文字不屬於 HTML 翻譯範圍；嵌入服務旁有英文說明。

## 建置與維護

1. 安裝 Node 依賴，及 `python -m pip install -r scripts/bilingual-requirements.txt`。
2. `npm run build` 先建立原網站、統一導航，再擷取顯示文字並產生英文 HTML。
3. `src/data/i18n/en.json` 是完整翻譯快取；`en-overrides.json` 是經編輯核對的優先譯文。不要翻譯表單 value、ID、程式碼或會員儲存資料。
4. 新增中文內容後，建置程序只在本機／CI 使用 Argos 中文英文 1.9 模型翻譯新的句子。沒有翻譯 API 金鑰或付費服務，也不會把會員資料傳至翻譯商。
5. 每次發稿須檢查新增英文標題、日期、數字、否定詞與資格。更正譯文請加入 overrides，不直接改產生的 dist。
6. 英文頁有自己的 canonical、lang、OG locale、JSON-LD 與英文 sitemap；中文與英文都有互相對應的 hreflang。
7. 動態結果只翻譯 DOM 顯示文字，保留原始選項值與會員資料格式。獎學金英文搜尋索引包含已譯出的卡片文字。

測試應包含同頁切換、參數保留、手機版、新聞全文、獎學金英文搜尋與清除、DIY 篩選及英文 sitemap。機器翻譯不可冒稱逐句人工翻譯，無法代替招生資訊查核。

模型來源：https://github.com/argosopentech/argospm-index

模型輸入先用 OpenCC 將繁體字正規化成模型訓練所用簡體字；中文網站與原始稿件不變。所有日期、金額、資格與專有名稱仍須人工核對。
